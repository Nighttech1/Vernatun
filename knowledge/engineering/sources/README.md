# sources/ (корень engineering)

Большие базы лежат **в подпапках агентов**, не в корне:

- `architect/`, `frontend/`, `backend/`, `ai_bridge/`
- `tester/`, `fixer/`, `deployer/`

Сюда кладут учебники и паттерны, полезные **любой** команде (архитектура, API, тесты, деплой).  
Не класть законы, бренд и домен конкретного продукта — для этого `knowledge/area_*` в целевом репозитории.

См. [../_index.md](../_index.md).
