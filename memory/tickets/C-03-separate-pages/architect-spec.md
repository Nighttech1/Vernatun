# C-03 Отдельные страницы разделов

## Границы

Статические страницы в корне сайта. Не трогать данные клуба на сервере и подкаст-плеер, кроме ссылки на него.

## Страницы

- `index.html` — только входная страница, без блоков «О нас», расписания, материалов и контактов.
- `about.html` — о клубе, форматы, атмосфера, вопросы.
- `schedule.html` — календарь сентября и карточка справа.
- `materials.html` — учебные материалы.
- `contacts.html` — контакты и соцсети.
- `articles.html` + отдельные тексты в `articles/`.

## Меню

Общая шапка на всех этих страницах. Выпадающий список — только ссылки, без левого заголовка и поясняющего текста.
