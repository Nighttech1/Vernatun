# C-01 Хедер-разделы

## Границы

Только `index.html`. Не трогать подкасты, галерею, FAQ-тексты, данные сервера.

## Приёмка

Сверху страницы — липкий хедер в духе mega-menu: четыре раздела «О нас», «Расписание», «Учебные материалы», «Контакты». У пунктов с подразделами — выпадающая панель с коротким текстом, не плоская полоска ссылок. На узком экране — меню-шторка. Якоря не прячутся под шапкой.
